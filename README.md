# LibraryMvc — КТ-2 «Web-приложение на Spring MVC»

Веб-приложение «Библиотека»: каталог книг с поиском, просмотром, добавлением, редактированием и удалением.
Технологии: **Java 17+, Spring Boot 3.5.6, Spring MVC, Thymeleaf, Bean Validation, Maven**. Хранилище — в памяти.

## Запуск

**IntelliJ IDEA:** `File → Open` → выбрать `pom.xml` → *Open as Project* → дождаться загрузки Maven →
запустить `LibraryApplication` (зелёный треугольник рядом с `main`).

**Командная строка:**
```
mvn clean package
java -jar target/library-mvc-1.0.0.jar
```

После запуска открыть в браузере: **http://localhost:8080**. Остановить приложение: красный квадрат в IDEA.
При старте добавляются 6 тестовых книг.

## Архитектура (MVC + слои)

```
Браузер ──► Controller ──► Service ──► Repository ──► хранилище (в памяти)
               │
               └──► View (Thymeleaf-шаблон) ◄── Model (данные для страницы)
```

| Слой | Пакет | Классы | Ответственность |
|------|-------|--------|-----------------|
| Controller | `controller` | `HomeController`, `BookController`, `GenreController` | принимают GET/POST, вызывают сервис, выбирают страницу |
| Service | `service` | `BookService` | бизнес-логика: поиск, проверка дубликатов, преобразование формы в книгу |
| Repository | `repository` | `BookRepository` (интерфейс), `InMemoryBookRepository` | только хранение; можно заменить на БД, не меняя сервис |
| Model | `model`, `dto` | `Book`, `Genre`, `BookForm`, `GenreStat` | данные; `BookForm` содержит правила валидации |
| View | `resources/templates` | `index`, `books/*`, `genres/*`, `error/*`, `fragments/layout` | HTML-страницы Thymeleaf |
| Ошибки | `exception` | `GlobalExceptionHandler` и классы исключений | единая обработка 404/405/500 |

## Контроллеры и адреса

| Контроллер | Метод и адрес | Что делает |
|------------|---------------|------------|
| `HomeController` | `GET /` | главная: статистика и последние книги |
| | `GET /test-500` | специальный адрес, чтобы проверить страницу ошибки 500 |
| `BookController` | `GET /books?q=...&genre=...` | список с поиском и фильтром по жанру |
| | `GET /books/{id}` | страница книги |
| | `GET /books/new` | форма добавления |
| | `POST /books` | создание книги (с валидацией) |
| | `GET /books/{id}/edit` | форма редактирования |
| | `POST /books/{id}` | сохранение изменений (с валидацией) |
| | `POST /books/{id}/delete` | удаление |
| `GenreController` | `GET /genres` | жанры с количеством книг |
| | `GET /genres/{code}` | книги выбранного жанра, например `/genres/fantasy` |

## Валидация формы (`BookForm`)

| Поле | Правила |
|------|---------|
| Название | `@NotBlank`, `@Size(2..100)` |
| Автор | `@NotBlank`, `@Size(2..80)` |
| Год | `@NotNull`, `@Min(1450)`, `@Max(2100)` |
| Страниц | `@NotNull`, `@Min(1)`, `@Max(5000)` |
| Жанр | `@NotNull` |
| Описание | `@Size(max = 500)` |

Дополнительно сервис запрещает дубликат: две книги с одинаковыми названием и автором (ошибка у поля «Название»).
При ошибке форма остаётся открытой, введённые данные сохраняются, под полями видны сообщения.

## Обработка ошибок

`GlobalExceptionHandler` (`@ControllerAdvice` + `@ExceptionHandler`):

| Ситуация | Пример | Результат |
|----------|--------|-----------|
| Нет книги или жанра | `/books/999`, `/genres/abc` | страница 404 с понятным сообщением |
| Несуществующий адрес | `/abc` | страница 404 |
| Вместо числа текст | `/books/abc` | страница 404 |
| Адрес только для POST открыт ссылкой | `/books/1/delete` | страница с ошибкой 405 |
| Непредвиденная ошибка | `/test-500` | страница 500 (подробности только в логе сервера) |
